  • PNG 圖集 + JSON Atlas：適合 Phaser、Godot、Unity、PixiJS、Aseprite。
  • 單檔 JS（.mjs）：零外部依賴，適合 HTML5 Canvas、React、Vue。
  • Choose from 4 mineral palettes, adjust paper grain (0–3), and lock a 32-bit seed.
  • PNG Sheet + JSON Atlas: Ready for Phaser, Godot, Unity, PixiJS, and Aseprite.
  • Single-File JS (.mjs): Zero-dependency ES module for Canvas, React, and Vue.

貳 WEB & FRONTEND / 網頁與前端框架串接

零依賴單檔 JS 模組（.mjs）。

在工作台點選「複製單檔 JS」或「單檔 JS ↓」，即可取得完全獨立、無須安裝任何套件的 ES Module。每個模組皆匯出 meta、act 與 create({ seed, palette })。

Click Copy Single-File JS or Download Single-File JS in the studio to get a self-contained ES module exporting meta, act, and create({ seed, palette }) with zero external dependencies.

1. HTML5 Canvas 即時播放 / Vanilla Canvas Live Playback 
import { create, meta } from './sword-qi-slash.mjs';

const canvas = document.querySelector('#ink-canvas');
canvas.width = meta.w;
canvas.height = meta.h;
const ctx = canvas.getContext('2d');

const fx = create({ seed: 42, palette: 'zhusha' });
const pixels = new ImageData(meta.w, meta.h);

let lastTime;
function tick(now) {
  if (lastTime !== undefined) {
    const dt = Math.min((now - lastTime) / 1000, 0.05);
    fx.step(meta.loop ? dt : Math.min(dt, meta.duration - fx.t));
  }
  lastTime = now;
  ctx.putImageData(fx.draw(pixels), 0, 0);

  if (meta.loop || fx.t < meta.duration) {
    requestAnimationFrame(tick);
  }
}
requestAnimationFrame(tick);
2. React 元件封裝 / React Component (InkEffect.jsx) 
import { useEffect, useRef } from 'react';
import { create, meta } from './sword-qi-slash.mjs';

export default function InkEffect({ seed = 42, palette = 'songyan' }) {
  const canvasRef = useRef(null);

  useEffect(() => {
    const ctx = canvasRef.current.getContext('2d');
    const fx = create({ seed, palette });
    const pixels = new ImageData(meta.w, meta.h);
    let last, rafId;

    function render(now) {
      if (last !== undefined) {
        const dt = Math.min((now - last) / 1000, 0.05);
        fx.step(meta.loop ? dt : Math.min(dt, meta.duration - fx.t));
      }
      last = now;
      ctx.putImageData(fx.draw(pixels), 0, 0);
      if (meta.loop || fx.t < meta.duration) rafId = requestAnimationFrame(render);
    }
    rafId = requestAnimationFrame(render);
    return () => cancelAnimationFrame(rafId);
  }, [seed, palette]);

  return <canvas ref={canvasRef} width={meta.w} height={meta.h} />;
}
3. Vue 3 元件封裝 / Vue 3 Component (InkEffect.vue) 
<script setup>
import { ref, watchPostEffect } from 'vue';
import { create, meta } from './sword-qi-slash.mjs';

const props = defineProps({
  seed: { type: Number, default: 42 },
  palette: { type: String, default: 'songyan' },
});
const canvasRef = ref(null);

watchPostEffect((onCleanup) => {
  const canvas = canvasRef.value;
  if (!canvas) return;
  const ctx = canvas.getContext('2d');
  const fx = create({ seed: props.seed, palette: props.palette });
  const pixels = new ImageData(meta.w, meta.h);
  let last, rafId;

  function render(now) {
    if (last !== undefined) {
      const dt = Math.min((now - last) / 1000, 0.05);
      fx.step(meta.loop ? dt : Math.min(dt, meta.duration - fx.t));
    }
    last = now;
    ctx.putImageData(fx.draw(pixels), 0, 0);
    if (meta.loop || fx.t < meta.duration) rafId = requestAnimationFrame(render);
  }
  rafId = requestAnimationFrame(render);
  onCleanup(() => cancelAnimationFrame(rafId));
});
</script>

<template>
  <canvas ref="canvasRef" :width="meta.w" :height="meta.h" />
</template>

叁 GAME ENGINES / 遊戲引擎圖集串接

PNG 序列圖集 + JSON Atlas。

匯出的透明 PNG 圖集與 JSON Atlas 相容於 Phaser 3、Godot 4、PixiJS、Unity 與 Aseprite，且在 meta.inkfx 內附精確的原點座標（origin）與命中頓幀（hits）。

Exported straight-alpha PNG sprite sheets and JSON atlases work out of the box with Phaser 3, Godot 4, PixiJS, Unity, and Aseprite, carrying origin coordinates and hit-stop timings inside meta.inkfx.

Phaser 3 — 載入圖集並對齊出招原點 / Load Atlas & Align Origin 
// preload()
this.load.atlas(
  'sword-qi',
  'assets/sword-qi-slash-zhusha-seed42.png',
  'assets/sword-qi-slash-zhusha-seed42.json'
);

// create()
const texture = this.textures.get('sword-qi');
const ink = texture.customData.meta.inkfx;
const frames = texture
  .getFrameNames()
  .sort()
  .map((frame) => ({ key: 'sword-qi', frame }));

this.anims.create({
  key: ink.id,
  frames,
  frameRate: ink.fps,
  repeat: ink.loop ? -1 : 0,
});

const sprite = this.add.sprite(player.x, player.y, 'sword-qi', frames[0].frame);
sprite.setOrigin(ink.origin.x / sprite.width, ink.origin.y / sprite.height);
sprite.play(ink.id);
Godot 4 — 使用隨附載入器建立 AnimatedSprite2D / Godot 4 Atlas Loader 
const InkFXAtlas = preload("res://inkfx_atlas.gd")

func _ready() -> void:
    var frames := InkFXAtlas.load_frames("res://fx/sword-qi-slash-zhusha-seed42.json")
    var meta: Dictionary = frames.get_meta(&"inkfx")
    $AnimatedSprite2D.sprite_frames = frames
    $AnimatedSprite2D.centered = false
    $AnimatedSprite2D.offset = -Vector2(meta["origin"]["x"], meta["origin"]["y"])
    $AnimatedSprite2D.play(meta["id"])
引擎 / 工具 匯入與設定方式 / Integration Steps
PixiJS 將 PNG 材質與 JSON 傳入 new PIXI.Spritesheet(texture, atlasJson)，呼叫 await spritesheet.parse() 後即可用 PIXI.AnimatedSprite 播放。 Pass the PNG texture and JSON into new PIXI.Spritesheet(texture, atlasJson), call await spritesheet.parse(), and play via PIXI.AnimatedSprite.
Unity 將 PNG 設為 Sprite (2D and UI)、Sprite Mode: Multiple，於 Sprite Editor 選擇 Grid By Cell Size，輸入 JSON 第一格的 sourceSize.w / h（如 224 × 224）自動切片。 Set Texture Type to Sprite (2D and UI) and Sprite Mode: Multiple, then slice in Sprite Editor using Grid By Cell Size with sourceSize.w / h.
Aseprite 選擇 File → Import Sprite Sheet，排列設為橫向列優先（By Rows），填入單格寬高即可逐格檢視或二次編輯。 Use File → Import Sprite Sheet in row-major order with the native frame width and height.

肆 TIMING & PALETTES / 招式時間軸、頓幀與四色礦物色階

內建打擊節奏與礦物墨韻。

每一式特效皆內建結構化的動作時間點（meta 與 act），匯出的圖集本身已烘焙命中頓幀定格畫面，播放時無須對特效重複暫停，可直接用 freeze 與 shakeAmp 同步控制受擊角色與鏡頭震動。

Every effect exports structured timing metadata (meta & act). Exported sprite sheets already bake in hit-stop freeze frames—use freeze and shakeAmp directly to lock target characters and drive camera shake.

欄位 / Field 型別 說明與遊戲邏輯搭配 / Gameplay Usage
meta.w, meta.h number 畫布原生像素尺寸（招式為 224 × 224，部分全幅轉場為 256 × 192） / Native canvas pixel size
meta.ox, meta.oy number 招式在畫布內的局部原點座標（用於對齊角色刀柄、掌心或陣眼） / Local origin inside the canvas
meta.duration number 總顯示時長（秒），包含起勢、命中頓幀與收勢 / Total display duration in seconds
act.windup number 起勢蓄墨秒數；顯示時間 t === act.windup 即為出招瞬間 / Windup telegraph seconds
act.hits[i].t number 相對出招瞬間的命中秒數（顯示時間軸位置為 act.windup + hit.t） / Impact-relative hit timestamp
act.hits[i].freeze number 命中頓幀秒數（Hit-Stop），可用於同步鎖定受擊目標硬直 / Hit-stop duration in seconds
act.hits[i].shakeAmp number 建議鏡頭震動幅度（像素） / Recommended camera-shake amplitude in pixels

伍 CUSTOM BRUSHWORK / 進階：自訂筆觸與新招式創作

以程式碼運筆：120Hz 飛白與濕墨擴散。

若想直接呼叫底層筆觸 API 創作新招式，可從輕量入口 src/runtime.js 匯入 createEffect、stamp、stroke 與 arc。當 pigment + wetness > paperGrain[i] * dryFactor 時墨跡才會落紙，調高 dryFactor 即可畫出自然蒼勁的飛白。

Import createEffect, stamp, stroke, and arc from src/runtime.js to author custom effects. Ink deposits where pigment + wetness > paperGrain[i] * dryFactor, carving natural flying-white bristles.

自訂一式飛白斬擊 / Custom Sword Slash Effect 
import { createEffect, arc, stamp, mulberry32 } from './src/runtime.js';

export const meta = {
  id: 'custom-slash', name: '自訂一字斬', category: 'sword',
  duration: 1.1, loop: false, w: 224, h: 224, ox: 112, oy: 112,
};

export const act = {
  windup: 0.25,
  poses: [[-0.25, 'WINDUP', 'easeOut'], [0.0, 'STRIKE', 'snap'], [0.2, 'RECOVER', 'easeOut']],
  hits: [{ t: 0.03, freeze: 0.12, shakeAmp: 3, inkSplash: 18 }],
};

export function create({ seed = 1, palette = 'songyan' } = {}) {
  const rand = mulberry32(seed);
  const jitter = (rand() - 0.5) * 0.15;

  return createEffect(meta, act, (frame, actionTime, prevActionTime) => {
    // 1. 起勢蓄墨 (Windup: actionTime < 0)
    if (actionTime < 0) {
      stamp(frame, frame.ox - 48, frame.oy + 12, 4, { pigment: 0.35, wetness: 0.4, dryFactor: 1.1 });
      return;
    }
    // 2. 出鋒斬擊瞬間 (Strike release at actionTime === 0)
    if (prevActionTime <= 0 && actionTime >= 0) {
      arc(frame, {
          start: -2.6 + jitter, end: -0.3 + jitter, radius: 72,
          width: 12, pigment: 0.92, wetness: 0.55, dryFactor: 1.45,
      });
      // 點綴朱砂火星 (Cinnabar sparks with tint: 1)
      for (let i = 0; i < 6; i++) {
        stamp(frame, frame.ox + 20 + i * 9, frame.oy - 18 - i * 4, 2.5, {
          pigment: 0.85, wetness: 0.2, tint: 1,
        });
      }
    }
  }, { seed, palette });
}
